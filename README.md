# ndsh

Neovim chat UI for [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (dsh).

`ndsh` is a Lua plugin that spawns `dsh --profile sdk` and drives it over the
SDK's newline-delimited JSON-RPC protocol, rendering the session in native
Neovim buffers.

Status: early development. See `doc/ndsh.txt` for usage once the plugin
exists.
